# Guías

Cada archivo `.md` de este directorio se publica en `/guias/<nombre-del-archivo>`.

Formato mínimo:

```markdown
---
title: Título de la guía
updated: 2026-11-10
---

# Título de la guía

Contenido en Markdown.
```

- El nombre del archivo es el slug: solo minúsculas, números y guiones.
- Este `README.md` no se publica.
- Sin archivos aquí, `/guias` muestra su estado vacío. No se inventan guías de ejemplo.
